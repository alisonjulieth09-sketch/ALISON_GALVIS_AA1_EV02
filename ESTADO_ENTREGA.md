# Estado de esta entrega

Se amplió el código fuente recibido con módulos REST de clientes, categorías, inventario y ventas. Se añadieron documentación funcional, manual técnico, configuración de ambientes, matriz de pruebas y PDF de informe.

**No se ha podido compilar ni ejecutar esta versión en el entorno de preparación porque Maven no está instalado.** Por tanto, no se certifica aquí que `mvn clean test` haya pasado. Ejecuta los comandos del README en un equipo con JDK 17 y Maven, corrige cualquier incidencia que aparezca y conserva la salida de consola.

Tampoco se ha publicado un despliegue web. Las direcciones localhost son exclusivamente locales. La URL de GitHub fue heredada del archivo original y debe comprobarse después de subir estos cambios.

Antes de entregar:
1. Completar datos de portada.
2. Ejecutar pruebas y guardar capturas.
3. Generar el JAR.
4. Verificar el repositorio.
5. Desplegar si la guía/instructor exige URL pública.
6. Adjuntar acta real de aprobación de requisitos cuando aplique.
